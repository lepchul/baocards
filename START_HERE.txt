BAO CARDS - С ЧЕГО НАЧАТЬ

1. Создай бота в @BotFather через /newbot.
2. Скопируй .env.example в .env, заполни BOT_TOKEN.
3. В config.json поставь свой Telegram ID в admin_ids.
   Если ID неизвестен, запусти бота и отправь /id,
   затем исправь config.json и перезапусти.
4. На сервере с Docker: docker compose up -d --build
5. В личке бота: /admin -> Добавить карту.
   Введи название, редкость, цену, очки и загрузи фото.
6. Напиши бао.

Для групп: @BotFather -> /setprivacy -> бот -> Disable.
Если режим не обновился, удали бота из группы и добавь снова.

Подробные инструкции, Python-хостинг и бэкапы: README.md.
Админка находится в Telegram. Отдельного сайта нет.
Начальный каталог пустой, фотографии добавляет администратор.
Запускай только один экземпляр бота, используй постоянный диск.
